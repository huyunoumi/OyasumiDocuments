利用規約

本利用規約（以下「本規約」）は、 おやすみダイアリー（以下「本アプリ」）の 利用条件を定めるものです。

1. 適用

ユーザーは、本規約に同意した上で 本アプリを利用するものとします。

2. 提供機能

本アプリは以下の機能を提供します。

  • 日記作成・閲覧（過去の日記を期間の制限なく閲覧できます）
  • 週感想の記録
  • 月単位の振り返り
  • 日記の検索
  • アプリロック（Face ID / Touch ID / パスコード）
  • 去年の今日の日記の表示（プレミアム）
  • iCloudへのバックアップおよび復元（プレミアム）
  • AIによる振り返り（AIプラン）

3. 有料プラン

一部機能は、以下の有料プランで提供されます。 各プランの価格は、アプリ内およびApp Storeに表示します。

  • プレミアム：一度の購入で利用できる買い切りのプランです。
  • AIプラン：月額または年額の自動更新サブスクリプションです。プレミアムの機能も利用できます。初めて加入する場合は、無料体験期間が設定されることがあります。

課金処理はAppleのApp Storeを通じて行われます。 返金はAppleの定める規定に従います。

4. 自動更新サブスクリプション

  • AIプランは、現在の期間が終了する24時間以上前に解約しない限り、同じ期間・料金で自動的に更新されます。
  • 更新料金は、現在の期間が終了する前の24時間以内に、Apple アカウントに請求されます。
  • 無料体験期間がある場合、無料体験期間の終了までに解約しなければ、有料の期間に自動的に移行します。
  • 解約は、iPhoneの「設定」→ ユーザー名 →「サブスクリプション」から行えます。アプリを削除しても解約にはなりません。
  • 期間の途中で解約した場合も、その期間が終了するまでAIプランを利用できます。期間途中の解約による日割りの返金は行いません。
  • AIプランが終了した後も、生成済みのAI振り返りは閲覧できます。

5. AI振り返り

  • AI振り返りは、ユーザーの日記・感想をもとにAIが自動で生成するものです。内容の正確性、完全性、有用性を保証しません。
  • AI振り返りは、医療、心理、法律その他の専門的な助言ではありません。必要な場合は専門家にご相談ください。
  • AI振り返りの生成には、1か月あたりの回数の上限があります。
  • 開発者は、AI振り返りに使うAIのモデル、生成の方法および回数の上限を変更する場合があります。
  • AI振り返りを生成する際の情報の送信については、プライバシーポリシーに定めます。

6. バックアップ

iCloudへのバックアップは、ユーザー自身のiCloudを利用します。 iCloudの空き容量の不足や通信環境、Appleのサービスの状況により、 バックアップまたは復元ができない場合があります。 復元を行うと、端末内の日記・感想・AI振り返りはバックアップの内容に置き換わります。

  • 運営を妨害する行為
